# Documentação

## Módulos

- [Autenticação](modulos/autenticacao/autenticacao.md): cadastro de usuários e login, com papéis Cliente, Restaurante e Entregador. Integração: [Integrar com Autenticação](modulos/autenticacao/autenticacao-api.md).

- [Pedidos](modulos/pedidos/pedidos.md): pedido de um cliente a um restaurante, com itens e etapas. Integração: [Integrar com Pedidos](modulos/pedidos/pedidos-api.md).
