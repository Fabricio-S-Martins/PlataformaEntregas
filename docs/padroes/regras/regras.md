# regras

Regras que o código e os testes do projeto seguem.

## Itens

- [ferramentas](ferramentas.md): ferramentas do projeto, com comando de conferência e de instalação.
- [praticas](praticas.md): práticas de código adotadas (LSP, DIP, Demeter, indentação por método etc.).
- [testes](testes.md): regras e nomenclatura dos testes xUnit.
