# ferramentas

Ferramentas que o projeto usa, com o comando para conferir e para instalar.

- csharp-ls — conferir: `dotnet tool list -g` (procurar `csharp-ls`) — instalar: `dotnet tool install -g csharp-ls`
- csharp-lsp — conferir: `claude plugin list` (procurar `csharp-lsp`) — instalar: `claude plugin marketplace add anthropics/claude-plugins-official` (se faltar) e `claude plugin install csharp-lsp@claude-plugins-official`
